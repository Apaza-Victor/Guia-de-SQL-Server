Glosario de términos SQL

Definiciones concisas de los conceptos, comandos y acrónimos más importantes de SQL Server, ordenadas alfabéticamente.

A B C D F G I N P S T U V W

A

ACID
Acrónimo de Atomicity, Consistency, Isolation, Durability. Conjunto de propiedades que garantizan que las transacciones en bases de datos se procesan de forma fiable y segura.
ALTER
Comando DDL utilizado para modificar la estructura de objetos existentes en la base de datos, como tablas, vistas o procedimientos almacenados.

B

Base de datos
Colección organizada de datos estructurados que se almacenan y gestionan electrónicamente. SQL Server es un sistema gestor de bases de datos relacionales (RDBMS).

C

Clave foránea (FOREIGN KEY)
Campo o conjunto de campos en una tabla que se relaciona con la clave primaria de otra tabla, estableciendo integridad referencial entre ambas.
Clave primaria (PRIMARY KEY)
Restricción que identifica de forma única cada fila de una tabla. No permite valores NULL y garantiza la unicidad de los registros.
CREATE
Comando DDL utilizado para crear nuevos objetos en la base de datos, como bases de datos, tablas, índices, vistas y procedimientos almacenados.
CTE (Common Table Expression)
Expresión de tabla común que permite definir un conjunto de resultados temporal con nombre, útil para consultas recursivas y subconsultas complejas.
Cursor
Mecanismo de T-SQL que permite recorrer fila por fila el resultado de una consulta. Se recomienda evitar su uso en favor de operaciones basadas en conjuntos.

D

DCL (Data Control Language)
Subconjunto de SQL que incluye comandos para gestionar permisos y control de acceso como GRANT, REVOKE y DENY.
DDL (Data Definition Language)
Subconjunto de SQL que incluye comandos para definir y modificar la estructura de los objetos de la base de datos: CREATE, ALTER, DROP, TRUNCATE.
DML (Data Manipulation Language)
Subconjunto de SQL que incluye comandos para manipular datos: SELECT, INSERT, UPDATE, DELETE.
DQL (Data Query Language)
Subconjunto de SQL centrado exclusivamente en consultas de datos. El comando principal es SELECT. A menudo se considera parte de DML.
DROP
Comando DDL que elimina permanentemente un objeto de la base de datos (tabla, vista, índice, etc.). Esta operación no se puede deshacer.

F

FOREIGN KEY
Restricción que establece una relación entre dos tablas, garantizando que los valores de una columna coincidan con los valores de la clave primaria de otra tabla.

G

GRANT
Comando DCL que otorga permisos específicos a usuarios o roles sobre objetos de la base de datos (SELECT, INSERT, EXECUTE, etc.).
GROUP BY
Cláusula de SELECT que agrupa filas con valores idénticos en columnas especificadas, permitiendo aplicar funciones de agregación (COUNT, SUM, AVG, etc.).

I

INDEX
Estructura de datos que mejora la velocidad de las consultas al permitir búsquedas rápidas de filas. SQL Server usa índices agrupados (clustered) y no agrupados (nonclustered).
INNER JOIN
Tipo de JOIN que devuelve solo las filas que tienen valores coincidentes en ambas tablas. Es el tipo de combinación más común en SQL.
INSERT
Comando DML que agrega una o más filas nuevas a una tabla existente en la base de datos.

N

NULL
Valor especial en SQL que representa la ausencia de un dato o un valor desconocido. No es igual a cero ni a una cadena vacía. Las comparaciones con NULL requieren IS NULL o IS NOT NULL.

P

PRIMARY KEY
Restricción que combina unicidad y no nulidad para identificar de forma exclusiva cada registro de una tabla. Cada tabla puede tener solo una clave primaria.

S

SELECT
Comando DML/DQL utilizado para recuperar datos de una o más tablas. Es la instrucción más usada en SQL y permite filtrar, ordenar y agrupar resultados.
Stored Procedure
Bloque de código T-SQL precompilado almacenado en el servidor que encapsula lógica de negocio. Puede aceptar parámetros y devolver resultados. Se ejecuta con EXEC.

T

TRIGGER
Tipo especial de procedimiento almacenado que se ejecuta automáticamente en respuesta a eventos como INSERT, UPDATE o DELETE sobre una tabla o vista.
TRUNCATE
Comando DDL que elimina todas las filas de una tabla de forma rápida, liberando el espacio de almacenamiento. A diferencia de DELETE, no registra eliminaciones fila por fila en el log.

U

UNION
Operador que combina los resultados de dos o más consultas SELECT en un único conjunto de resultados, eliminando filas duplicadas por defecto. UNION ALL las conserva.

V

VIEW (Vista)
Tabla virtual basada en el resultado de una consulta SELECT almacenada. Las vistas simplifican consultas complejas y añaden una capa de seguridad sobre los datos subyacentes.

W

WHERE
Cláusula de SELECT, UPDATE o DELETE que filtra filas basándose en una condición booleana. Solo las filas que cumplen la condición son incluidas en el resultado.
