Acerca de esta guía

¿Qué es esta guía?

SQL Server es uno de los motores de bases de datos más utilizados en el mundo empresarial. Esta guía está diseñada para llevarte desde cero hasta un nivel avanzado/experto, combinando teoría, ejemplos prácticos y buenas prácticas, todo en un solo recurso navegable y gratuito.

Cubre 12 niveles con 46 temas que abarcan desde los fundamentos de bases de datos hasta integración con backend, administración, optimización y temas avanzados como particionamiento, Always On y CTEs recursivos.

¿Para quién es?

  • Principiantes absolutos que nunca han usado una base de datos y quieren empezar desde cero.
  • Desarrolladores que necesitan integrar SQL Server en sus aplicaciones con PHP, Node.js, Python, .NET o Java.
  • Analistas de datos que quieren mejorar sus consultas y entender el modelo relacional a fondo.
  • Administradores de bases de datos en formación que buscan una referencia completa y estructurada.
  • Profesionales experimentados que desean repasar conceptos avanzados o prepararse para certificaciones.

Stack tecnológico

Esta guía está construida con las siguientes tecnologías:

  • HTML5 semántico — Estructura accesible y compatible con navegadores modernos.
  • Bootstrap 5 — Sistema de rejilla responsivo y utilidades CSS.
  • CSS personalizado — Variables CSS para temas oscuro/claro, animaciones y componentes propios.
  • AOS (Animate On Scroll) — Animaciones de entrada al hacer scroll.
  • Bootstrap Icons — Librería de iconos vectoriales.
  • JavaScript vanilla — Carga dinámica de partials (header/footer), cambio de tema y navegación.
  • SQL Server / T-SQL — Todos los ejemplos de código están escritos para SQL Server y probados en versiones 2019 y 2022.

Cómo usar la guía

La guía está diseñada para leerse de forma secuencial, pero cada tema también funciona como referencia independiente. Usa el mapa del temario en la página principal para navegar entre niveles. Cada página incluye botones de navegación al final para avanzar o retroceder. Puedes alternar entre tema oscuro y claro con el botón de sol/luna en la cabecera.
