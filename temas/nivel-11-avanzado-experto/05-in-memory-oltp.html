In-Memory OLTP

In-Memory OLTP (código原名 Hekaton) es una tecnología que optimiza tablas y procedimientos para que residan en memoria principal, eliminando latencias de E/S y bloqueos de recursos (locks/latches).

Escenarios específicos

In-Memory OLTP no es para todas las bases. Está diseñado para cuellos de botella de alta concurrencia y baja latencia: sistemas de trading, gaming, colas de mensajes, cachés. No mejora consultas analíticas (Data Warehouse).

Tablas Memory-Optimized

Estas tablas residen completamente en RAM. Se declaran con MEMORY_OPTIMIZED = ON.

T-SQL
-- Crear filegroup para In-Memory (una vez)
ALTER DATABASE MiBase
ADD FILEGROUP FG_InMemory CONTAINS MEMORY_OPTIMIZED_DATA;

ALTER DATABASE MiBase ADD FILE (
    NAME = N'InMemoryData',
    FILENAME = N'C:\Data\InMemoryData'
) TO FILEGROUP FG_InMemory;

-- Crear tabla memory-optimized
CREATE TABLE SessionCarrito (
    CarritoID   INT IDENTITY PRIMARY KEY NONCLUSTERED,
    UsuarioID   INT NOT NULL,
    ProductoID  INT NOT NULL,
    Cantidad    INT NOT NULL,
    INDEX ix_Carrito HASH (UsuarioID, ProductoID)
        WITH (BUCKET_COUNT = 100000)
) WITH (MEMORY_OPTIMIZED = ON, DURABILITY = SCHEMA_AND_DATA);

Índices en Tablas Memory-Optimized

Tipo de ÍndiceUsoCaracterística
HASHBúsquedas por igualdad (=)Muy rápido, necesita BUCKET_COUNT adecuado
NONCLUSTERED (Range)Búsquedas por rango (>, BETWEEN, ORDER BY)Árbol B en memoria, soporta ordenamiento
/* --- DURABILITY: SCHEMA_AND_DATA vs SCHEMA_ONLY --- */

SCHEMA_AND_DATA persiste los datos en disco (con checkpoint). SCHEMA_ONLY pierde los datos al reiniciar (ideal para tablas temporales o de sesión).

Procedimientos Compilados Nativamente

Se compilan a DLL nativa al crearse. No tienen overhead de interpretación y acceden directamente a las tablas en memoria sin locks.

T-SQL
CREATE PROCEDURE dbo.InsertarCarrito
    @UsuarioID  INT,
    @ProductoID INT,
    @Cantidad   INT
WITH NATIVE_COMPILATION, SCHEMABINDING,
     EXECUTE AS OWNER
AS
BEGIN ATOMIC WITH
    (TRANSACTION ISOLATION LEVEL = SNAPSHOT,
     LANGUAGE = N'spanish')

    INSERT INTO dbo.SessionCarrito
        (UsuarioID, ProductoID, Cantidad)
    VALUES (@UsuarioID, @ProductoID, @Cantidad);
END;
GO

Limitaciones

  • No soporta FK, CHECK, DEFAULT (en tablas memory-optimized)
  • Tamaño limitado por memoria RAM disponible
  • No soporta ALTER TABLE ... ADD COLUMN (debes recrear)
  • Los SP compilados nativamente no pueden usar funciones no inlineables
  • Solo disponible en Enterprise y Developer
