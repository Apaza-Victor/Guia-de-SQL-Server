CTE Recursivos

Un CTE (Common Table Expression) recursivo permite ejecutar consultas que se llaman a sí mismas, ideales para recorrer estructuras jerárquicas como organigramas, categorías o árboles.

Flujo de ejecución de un CTE recursivo en T-SQL
Recursión infinita

Sin OPTION (MAXRECURSION N) el límite por defecto es 100. Si tu recursión excede ese número, SQL Server detiene la consulta con un error. Usa MAXRECURSION 0 para ilimitado, pero con precaución.

Sintaxis Básica

T-SQL
WITH cte_nombre (columnas)
AS (
    -- Miembro ancla: consulta inicial
    SELECT ...
    FROM ...
    WHERE condicion_base

    UNION ALL

    -- Miembro recursivo: referencia al CTE
    SELECT ...
    FROM ... cte_nombre
    JOIN ...
    WHERE condicion_recursiva
)
SELECT * FROM cte_nombre;

Ejemplo 1: Jerarquía de Empleados

T-SQL
-- Tabla: Employees (EmployeeID, Name, ManagerID)
WITH EmployeeHierarchy AS (
    -- Ancla: CEO (sin manager)
    SELECT EmployeeID, Name, ManagerID, 0 AS Level,
           CAST(Name AS VARCHAR(500)) AS Path
    FROM Employees
    WHERE ManagerID IS NULL

    UNION ALL

    -- Recursivo: subordinados
    SELECT e.EmployeeID, e.Name, e.ManagerID,
           eh.Level + 1,
           CAST(eh.Path + ' -> ' + e.Name AS VARCHAR(500))
    FROM Employees e
    JOIN EmployeeHierarchy eh ON e.ManagerID = eh.EmployeeID
)
SELECT EmployeeID, Name, Level, Path
FROM EmployeeHierarchy
ORDER BY Path
OPTION (MAXRECURSION 50);

Ejemplo 2: Generar Rango de Fechas

T-SQL
DECLARE @StartDate DATE = '2026-01-01';
DECLARE @EndDate DATE = '2026-01-31';

WITH DateRange AS (
    SELECT @StartDate AS Fecha
    UNION ALL
    SELECT DATEADD(DAY, 1, Fecha)
    FROM DateRange
    WHERE Fecha < @EndDate
)
SELECT Fecha,
       DATENAME(WEEKDAY, Fecha) AS DiaSemana
FROM DateRange
OPTION (MAXRECURSION 365);

Ejemplo 3: Sucesión de Fibonacci

T-SQL
WITH Fibonacci (N, Fibonacci, Prev) AS (
    SELECT 1, 0, 0
    UNION ALL
    SELECT 2, 1, 0
    UNION ALL
    SELECT N + 1,
           Fibonacci + Prev,
           Fibonacci
    FROM Fibonacci
    WHERE N < 20
)
SELECT N, Fibonacci FROM Fibonacci
WHERE N >= 1
OPTION (MAXRECURSION 100);

/* --- Consejo: usa UNION ALL, no UNION --- */

En CTE recursivos usa siempre UNION ALL (no UNION), porque UNION intenta eliminar duplicados y eso rompe la recursión.
