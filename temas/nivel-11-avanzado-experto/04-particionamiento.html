Particionamiento

El particionamiento divide una tabla grande en segmentos más pequeños (particiones) basados en una columna clave. Cada partición se almacena en un filegroup distinto, mejorando la gestión y el rendimiento.

Ediciones de SQL Server

El particionamiento solo está disponible en las ediciones Enterprise, Developer y Standard (parcial, desde SQL 2016 SP1). En Standard, el límite es de 15,000 particiones y la compresión por partición no está disponible.

Componentes del Particionamiento

  • Partition Function: Define cómo se mapean los valores a particiones (rangos).
  • Partition Scheme: Asigna cada partición a un filegroup.
  • Tabla Particionada: Tabla que usa el esquema de partición en su clave de agrupamiento.

Crear una Tabla Particionada

T-SQL
-- 1. Crear filegroups (opcional, puede ser PRIMARY)
ALTER DATABASE MiBase ADD FILEGROUP FG_2024;
ALTER DATABASE MiBase ADD FILEGROUP FG_2025;
ALTER DATABASE MiBase ADD FILEGROUP FG_2026;

ALTER DATABASE MiBase ADD FILE (
    NAME = N'DB_2024', FILENAME = N'C:\Data\DB_2024.ndf'
) TO FILEGROUP FG_2024;

ALTER DATABASE MiBase ADD FILE (
    NAME = N'DB_2025', FILENAME = N'C:\Data\DB_2025.ndf'
) TO FILEGROUP FG_2025;

ALTER DATABASE MiBase ADD FILE (
    NAME = N'DB_2026', FILENAME = N'C:\Data\DB_2026.ndf'
) TO FILEGROUP FG_2026;

-- 2. Partition Function (por año)
CREATE PARTITION FUNCTION pf_Fecha (DATE)
AS RANGE RIGHT FOR VALUES (
    '2025-01-01', '2026-01-01', '2027-01-01'
);

-- 3. Partition Scheme
CREATE PARTITION SCHEME ps_Fecha
AS PARTITION pf_Fecha
TO (FG_2024, FG_2025, FG_2026, [PRIMARY]);

-- 4. Tabla particionada
CREATE TABLE Pedidos (
    PedidoID   INT      NOT NULL,
    Fecha      DATE     NOT NULL,
    ClienteID  INT      NOT NULL,
    Total      DECIMAL(10,2),
    CONSTRAINT PK_Pedidos PRIMARY KEY (PedidoID, Fecha)
) ON ps_Fecha (Fecha);

Partition Elimination

SQL Server automáticamente accede solo a las particiones relevantes cuando la consulta filtra por la clave de partición:

T-SQL
-- Solo accede a la partición 2025
SELECT COUNT(*)
FROM Pedidos
WHERE Fecha BETWEEN '2025-01-01' AND '2025-12-31';

Mantener Particiones: Sliding Window

El patrón sliding window agrega particiones nuevas y elimina las antiguas sin mover datos masivamente.

T-SQL
-- Agregar partición para 2028
ALTER DATABASE MiBase ADD FILEGROUP FG_2028;
ALTER DATABASE MiBase ADD FILE (
    NAME = N'DB_2028', FILENAME = N'C:\Data\DB_2028.ndf'
) TO FILEGROUP FG_2028;

-- SPLIT: crear nuevo rango
ALTER PARTITION SCHEME ps_Fecha
NEXT USED FG_2028;

ALTER PARTITION FUNCTION pf_Fecha()
SPLIT RANGE ('2028-01-01');

-- SWITCH: mover datos antiguos a tabla de staging
ALTER TABLE Pedidos SWITCH PARTITION 1 TO Staging_Pedidos;

-- MERGE: eliminar partición vacía
ALTER PARTITION FUNCTION pf_Fecha()
MERGE RANGE ('2024-01-01');

Beneficios

  • Mantenimiento más rápido (REBUILD por partición)
  • Carga y eliminación eficiente de datos (SWITCH)
  • Mejora de rendimiento en consultas con filtros por clave de partición
  • Distribución de datos en discos distintos
