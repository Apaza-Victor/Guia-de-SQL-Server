JSON en SQL Server

Desde SQL Server 2016, el motor incluye soporte nativo para JSON: puedes parsear, generar, modificar y validar documentos JSON directamente desde T-SQL.

JSON vs XML

JSON es más liviano que XML y se ha convertido en el formato estándar para APIs REST y aplicaciones web. SQL Server soporta ambos, pero JSON es hoy la opción más usada en integraciones modernas.

Generar JSON desde Consultas

T-SQL
-- FOR JSON PATH: control total sobre la estructura
SELECT
    ProductID AS 'id',
    Name      AS 'nombre',
    Price     AS 'precio'
FROM Products
WHERE CategoryID = 1
FOR JSON PATH, ROOT('productos');

/*
{
  "productos": [
    { "id": 1, "nombre": "Laptop", "precio": 1200 },
    { "id": 2, "nombre": "Mouse",  "precio": 25 }
  ]
}
*/

-- FOR JSON AUTO: estructura basada en las tablas
SELECT * FROM Products
FOR JSON AUTO;

Parsear JSON desde T-SQL

T-SQL
-- OPENJSON: convierte JSON a filas y columnas
DECLARE @json NVARCHAR(MAX) = N'[
    {"id": 1, "nombre": "Laptop", "precio": 1200},
    {"id": 2, "nombre": "Mouse",  "precio": 25}
]';

SELECT *
FROM OPENJSON(@json)
WITH (
    id     INT         '$.id',
    nombre NVARCHAR(100) '$.nombre',
    precio DECIMAL(10,2) '$.precio'
);

Funciones de Acceso a JSON

T-SQL
-- JSON_VALUE: extrae un valor escalar
SELECT JSON_VALUE(@json, '$[0].nombre') AS PrimerNombre;

-- JSON_QUERY: extrae un objeto/array
SELECT JSON_QUERY(@json, '$[0]') AS PrimerObjeto;

-- ISJSON: validación
SELECT ISJSON(@json) AS EsValido;  -- 1 = válido

-- JSON_MODIFY: modificar un valor
SELECT JSON_MODIFY(@json, '$[0].precio', 1300);

Ejemplo Práctico: API Response

T-SQL
-- Construir respuesta de API con metadatos
SELECT
    (SELECT COUNT(*) FROM Orders) AS total,
    (SELECT
        OrderID, OrderDate, CustomerName, Total
     FROM Orders o
     JOIN Customers c ON o.CustomerID = c.CustomerID
     ORDER BY OrderDate DESC
     OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY
     FOR JSON PATH) AS datos
FOR JSON PATH, WITHOUT_ARRAY_WRAPPER;
/*
{
  "total": 1500,
  "datos": [
    { "OrderID": 1501, "OrderDate": "2026-07-28", ... }
  ]
}
*/
/* --- JSON en columnas vs tablas relacionales --- */

Puedes almacenar JSON en columnas NVARCHAR(MAX) con restricciones CHECK (ISJSON(columna)=1). Sin embargo, para datos que necesitas filtrar frecuentemente, las columnas relacionales son más eficientes.
