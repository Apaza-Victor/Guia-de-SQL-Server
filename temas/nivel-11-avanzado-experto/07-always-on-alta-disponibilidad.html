Always On · Alta Disponibilidad

Always On Availability Groups (AG) es la solución de alta disponibilidad y disaster recovery de SQL Server. Proporciona replicación a nivel de base con failover automático o manual.

Windows Server Failover Clustering

Always On AG requiere Windows Server Failover Clustering (WSFC) como infraestructura subyacente. Cada nodo del AG debe ser parte del mismo clúster de conmutación por error.

Componentes de Always On

ComponenteDescripción
Availability Group (AG)Contenedor lógico de un conjunto de bases de datos que conmutan juntas
Primary ReplicaRéplica principal que acepta lecturas y escrituras
Secondary ReplicaRéplica(s) de solo lectura, pueden ser síncronas o asíncronas
ListenerNombre de red virtual (DNS) que los clientes usan para conectarse sin conocer la réplica activa
Failover Cluster Instance (FCI)Instancia de SQL Server instalada en varios nodos con almacenamiento compartido

Configurar un Availability Group

T-SQL
-- 1. Crear AG (ejecutar en réplica primaria)
CREATE AVAILABILITY GROUP [AG_Ventas]
WITH (AUTOMATED_BACKUP_PREFERENCE = SECONDARY)
FOR DATABASE [Ventas]
REPLICA ON
    N'SERVIDOR1' WITH (
        ENDPOINT_URL = N'TCP://SERVIDOR1:5022',
        AVAILABILITY_MODE = SYNCHRONOUS_COMMIT,
        FAILOVER_MODE = AUTOMATIC,
        SECONDARY_ROLE(ALLOW_CONNECTIONS = ALL)
    ),
    N'SERVIDOR2' WITH (
        ENDPOINT_URL = N'TCP://SERVIDOR2:5022',
        AVAILABILITY_MODE = SYNCHRONOUS_COMMIT,
        FAILOVER_MODE = AUTOMATIC,
        SECONDARY_ROLE(ALLOW_CONNECTIONS = ALL)
    ),
    N'SERVIDOR3' WITH (
        ENDPOINT_URL = N'TCP://SERVIDOR3:5022',
        AVAILABILITY_MODE = ASYNCHRONOUS_COMMIT,
        FAILOVER_MODE = MANUAL,
        SECONDARY_ROLE(ALLOW_CONNECTIONS = ALL)
    )
LISTENER N'ListenerVentas' (
    WITH IP = (N'192.168.1.100', N'255.255.255.0'),
    PORT = 1433
);

-- 2. Unir réplicas secundarias al AG
ALTER AVAILABILITY GROUP [AG_Ventas] JOIN;

-- 3. Iniciar sincronización de datos
ALTER DATABASE [Ventas] SET HADR AVAILABILITY GROUP = [AG_Ventas];

Failover Manual Planeado

T-SQL
-- Cambiar rol: primaria → secundaria (failover manual)
ALTER AVAILABILITY GROUP [AG_Ventas] FAILOVER;
