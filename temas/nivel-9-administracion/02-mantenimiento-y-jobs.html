Mantenimiento y Jobs

El mantenimiento regular es esencial para mantener el rendimiento y la integridad de SQL Server. Las tareas principales incluyen el mantenimiento de índices, la actualización de estadísticas y las comprobaciones de integridad.

Automatiza todo

Ninguna tarea de mantenimiento debe hacerse manualmente de forma regular. Usa SQL Server Agent o scripts programados para automatizar cada tarea.

Mantenimiento de Índices

Con el tiempo, los índices se fragmentan. La fragmentación degrada el rendimiento de las consultas.

T-SQL
-- Ver fragmentación de índices
SELECT OBJECT_NAME(ips.object_id) AS Tabla,
       i.name AS Indice,
       ips.avg_fragmentation_in_percent
FROM sys.dm_db_index_physical_stats(
    DB_ID(), NULL, NULL, NULL, 'LIMITED') ips
JOIN sys.indexes i ON ips.object_id = i.object_id
    AND ips.index_id = i.index_id
WHERE ips.avg_fragmentation_in_percent > 5
ORDER BY ips.avg_fragmentation_in_percent DESC;

-- REORGANIZE (5% - 30% fragmentación)
ALTER INDEX [IX_Nombre] ON dbo.Tabla REORGANIZE;

-- REBUILD (> 30% fragmentación)
ALTER INDEX [IX_Nombre] ON dbo.Tabla REBUILD;

-- REBUILD con opciones
ALTER INDEX [IX_Nombre] ON dbo.Tabla
REBUILD WITH (FILLFACTOR = 90, SORT_IN_TEMPDB = ON);

Actualización de Estadísticas

El optimizador de consultas usa estadísticas para estimar cardinalidades. Estadísticas desactualizadas provocan planes de ejecución subóptimos.

T-SQL
-- Actualizar todas las estadísticas de una base
EXEC sp_updatestats;

-- Actualizar estadísticas específicas
UPDATE STATISTICS dbo.Tabla [IX_Nombre]
WITH FULLSCAN;

DBCC CHECKDB — Integridad de la Base

Verifica la consistencia física y lógica de la base de datos. Debe ejecutarse al menos una vez por semana en producción.

T-SQL
-- Comprobación completa de integridad
DBCC CHECKDB ('MiBase') WITH NO_INFOMSGS;

-- CHECKDB con reparación (último recurso)
ALTER DATABASE MiBase SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
DBCC CHECKDB ('MiBase', REPAIR_ALLOW_DATA_LOSS);
ALTER DATABASE MiBase SET MULTI_USER;
REPAIR_ALLOW_DATA_LOSS

Usa REPAIR_ALLOW_DATA_LOSS solo como último recurso. Siempre intenta restaurar desde un backup primero. Esta opción puede eliminar datos para reparar la base.

Ola Hallengren

El script de mantenimiento de Ola Hallengren es la solución más utilizada en la comunidad SQL Server. Automatiza backups, index maintenance, estadísticas y CHECKDB con un solo script parametrizable.

T-SQL
-- Ejemplo de ejecución del script de Ola Hallengren
EXEC dbo.DatabaseIntegrityCheck
    @Databases = 'USER_DATABASES',
    @CheckCommands = 'CHECKDB',
    @LogToTable = 'Y';

EXEC dbo.IndexOptimize
    @Databases = 'USER_DATABASES',
    @FragmentationLow = 'INDEX_REORGANIZE',
    @FragmentationMedium = 'INDEX_REORGANIZE,INDEX_REBUILD_ONLINE',
    @FragmentationHigh = 'INDEX_REBUILD_OFFLINE',
    @UpdateStatistics = 'ALL',
    @LogToTable = 'Y';
