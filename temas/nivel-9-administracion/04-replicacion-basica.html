Replicación Básica

La replicación permite distribuir datos desde una base de origen (publicador) a una o más bases de destino (suscriptores). SQL Server soporta tres tipos principales de replicación.

Conceptos Clave

  • Publicador (Publisher): Base que origina los datos.
  • Distribuidor (Distributor): Base (puede ser la misma que el publicador) que almacena metadatos y datos en tránsito.
  • Suscriptor (Subscriber): Base que recibe y aplica los datos replicados.
  • Artículo: Objeto (tabla, vista, SP) que se replica.
  • Publicación: Colección de artículos.

Tipos de Replicación

TipoLatenciaUso IdealRequiere
SnapshotAltaTablas pequeñas, datos que cambian poco, inicialización de suscriptoresSnapshot Agent
TransactionalBaja (segundos)Alta disponibilidad de lectura, distribución de datos OLTP, reportesLog Reader Agent
MergeVariableEntornos desconectados o móviles, conflictos de escritura bidireccionalMerge Agent

Replicación Transaccional — La más usada

El Log Reader Agent lee el log de transacciones del publicador y replica cada cambio en los suscriptores casi en tiempo real. Ideal para distribuir datos operativos a servidores de reportes.

T-SQL
-- Configurar distribución (ejecutar en el distribuidor)
EXEC sp_adddistributor @distributor = N'SERVIDOR-DIST';
EXEC sp_adddistributiondb @database = N'distribution';

-- Habilitar base como publicador
EXEC sp_adddistributor_subscription
    @subscriber = N'SERVIDOR-SUB';

-- Crear publicación (en la base de datos del publicador)
EXEC sp_addpublication
    @publication = N'Pub_Ventas',
    @description = N'Replicación transaccional de Ventas',
    @sync_method = N'concurrent',
    @repl_freq = N'continuous',
    @status = N'active';

-- Agregar artículo
EXEC sp_addarticle
    @publication = N'Pub_Ventas',
    @article = N'Facturas',
    @source_object = N'Facturas',
    @type = N'logbased';

-- Crear suscripción (en el suscriptor)
EXEC sp_addsubscription
    @publication = N'Pub_Ventas',
    @subscriber = N'SERVIDOR-SUB',
    @destination_db = N'Ventas_Replica',
    @subscription_type = N'push';
Alternativas modernas

Para alta disponibilidad y distribución de datos, considera también Always On Availability Groups, que ofrece sincronización a nivel de base sin los overheads administrativos de la replicación tradicional.
