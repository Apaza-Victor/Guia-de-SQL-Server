SQL Server Agent

SQL Server Agent es el servicio de automatización y programación de tareas de SQL Server. Permite crear jobs, definir schedules, configurar alertas y notificar a operadores.

Agente en ejecución

SQL Server Agent es un servicio de Windows independiente. Debe estar en ejecución para que los jobs y alertas funcionen. Verifica su estado desde SQL Server Configuration Manager.

Componentes del Agente

ComponenteDescripción
JobConjunto de pasos (steps) que se ejecutan secuencialmente. Cada paso puede ser T-SQL, PowerShell, SSIS, etc.
ScheduleDefine cuándo se ejecuta un job: una vez, diario, semanal, mensual o al iniciar el Agente.
OperatorPersona o grupo que recibe notificaciones por email (Database Mail), pager o NET SEND.
AlertResponde a eventos específicos: errores de SQL Server, severidad, contadores de rendimiento o condiciones de WMI.

Crear un Job de Backup (Paso a Paso)

Ejemplo completo: job que realiza un backup FULL diario y notifica al operador.

T-SQL
-- 1. Crear operador
USE msdb;
GO
EXEC dbo.sp_add_operator
    @name = 'DBA Team',
    @email_address = 'dba@empresa.com',
    @enabled = 1;
GO

-- 2. Crear job
EXEC dbo.sp_add_job
    @job_name = 'Backup FULL Diario',
    @description = 'Backup completo de todas las bases de usuario',
    @owner_login_name = 'sa',
    @enabled = 1;
GO

-- 3. Agregar paso
EXEC dbo.sp_add_jobstep
    @job_name = 'Backup FULL Diario',
    @step_name = 'Backup FULL',
    @command = N'
        DECLARE @cmd NVARCHAR(MAX);
        SELECT @cmd = STRING_AGG(
            ''BACKUP DATABASE ['' + name + ''] TO DISK = ''''C:\Backups\'' + name + ''_FULL.bak'''' WITH COMPRESSION;'',
            CHAR(10))
        FROM sys.databases
        WHERE state = 0 AND database_id > 4;
        EXEC sp_executesql @cmd;',
    @database_name = 'msdb',
    @on_success_action = 1;
GO

-- 4. Crear schedule (diario a las 2 AM)
EXEC dbo.sp_add_schedule
    @schedule_name = 'Diario 2AM',
    @freq_type = 4,         -- diario
    @freq_interval = 1,
    @active_start_time = 020000;
GO

-- 5. Asignar schedule al job
EXEC dbo.sp_attach_schedule
    @job_name = 'Backup FULL Diario',
    @schedule_name = 'Diario 2AM';
GO

-- 6. Agregar notificación al operador
EXEC dbo.sp_add_notification
    @job_name = 'Backup FULL Diario',
    @operator_name = 'DBA Team',
    @notification_method = 1; -- email
GO

Historial de Jobs

Puedes consultar el historial de ejecución mediante T-SQL o desde SSMS.

T-SQL
-- Ver historial de un job
USE msdb;
GO
EXEC dbo.sp_help_jobhistory
    @job_name = 'Backup FULL Diario';

-- Limpiar historial antiguo
EXEC dbo.sp_purge_jobhistory
    @job_name = 'Backup FULL Diario',
    @oldest_date = '2026-01-01';
GO

Alertas

Las alertas pueden monitorear errores graves (severidad 19-25) o condiciones de rendimiento.

T-SQL
-- Alerta para error 823 (I/O errors)
EXEC dbo.sp_add_alert
    @name = 'Error 823 - I/O Error',
    @message_id = 823,
    @severity = 0,
    @enabled = 1,
    @job_name = 'Notificar DBA';
GO
