Conexión con PHP

PHP puede conectarse a SQL Server mediante dos extensiones principales: sqlsrv (nativa de Microsoft para Windows) y PDO (interfaz portable que también funciona en Linux).

Arquitectura de conexión desde múltiples lenguajes a SQL Server
Usa PDO para portabilidad

Si tu aplicación necesita funcionar en Windows y Linux, elige PDO. Cambiar de motor de base de datos solo requiere modificar el DSN. sqlsrv solo está disponible en Windows.

Conexión con sqlsrv

PHP
<?php
$server = 'localhost';
$database = 'MiBase';
$username = 'sa';
$password = 'ContraseñaSegura';

$conn = sqlsrv_connect($server, [
    'Database' => $database,
    'UID'      => $username,
    'PWD'      => $password,
    'Encrypt'  => true,
    'TrustServerCertificate' => true,
]);

if ($conn === false) {
    die(print_r(sqlsrv_errors(), true));
}

// Consulta con prepared statement
$stmt = sqlsrv_prepare($conn,
    'SELECT * FROM Usuarios WHERE email = ?',
    [&$email_param]
);
$email_param = 'user@example.com';
sqlsrv_execute($stmt);

while ($row = sqlsrv_fetch_array($stmt, SQLSRV_FETCH_ASSOC)) {
    echo $row['nombre'] . PHP_EOL;
}

sqlsrv_free_stmt($stmt);
sqlsrv_close($conn);

Conexión con PDO

PHP
<?php
$dsn = 'sqlsrv:Server=localhost;Database=MiBase;Encrypt=true;TrustServerCertificate=true';
$username = 'sa';
$password = 'ContraseñaSegura';

try {
    $pdo = new PDO($dsn, $username, $password, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]);

    // Prepared statement
    $stmt = $pdo->prepare('SELECT * FROM Usuarios WHERE email = :email');
    $stmt->execute([':email' => 'user@example.com']);

    foreach ($stmt as $row) {
        echo $row['nombre'] . PHP_EOL;
    }
} catch (PDOException $e) {
    echo 'Error: ' . $e->getMessage();
}

Manejo de Errores

Con sqlsrv usa sqlsrv_errors(). Con PDO configura el modo de error a ERRMODE_EXCEPTION para capturar excepciones.

PHP
// sqlsrv: obtener errores
if (sqlsrv_errors() !== null) {
    foreach (sqlsrv_errors() as $error) {
        echo "Código: {$error['code']} - {$error['message']}\n";
    }
}

// PDO: capturar excepción
try {
    $pdo->exec('INSERT INTO ...');
} catch (PDOException $e) {
    error_log('SQL Error: ' . $e->getMessage());
    throw $e;
}
