ORM y Connection Strings

Los ORMs (Object-Relational Mappers) facilitan el trabajo con bases de datos al abstraer las consultas SQL en código del lenguaje. Cada ecosistema tiene su ORM preferido para SQL Server.

Almacenamiento seguro

Nunca hardcodees connection strings en el código fuente. Usa variables de entorno, archivos .env, Azure Key Vault, o el administrador de secretos de tu plataforma (User Secrets en .NET, dotenv en Node.js, python-dotenv en Python).

Connection Strings Comunes

TEXTO
======= LOCAL (Windows Authentication) =======
Server=localhost;Database=MiBase;Integrated Security=True;TrustServerCertificate=True;

======= LOCAL (SQL Server Auth) =======
Server=localhost;Database=MiBase;User Id=sa;Password=MiPass123;TrustServerCertificate=True;

======= SERVIDOR DEDICADO =======
Server=192.168.1.100,1433;Database=MiBase;User Id=sa;Password=MiPass123;Encrypt=True;TrustServerCertificate=True;

======= AZURE SQL DATABASE =======
Server=tcp:miservidor.database.windows.net,1433;Database=MiBase;User Id=admin@miservidor;Password=MiPass123;Encrypt=True;TrustServerCertificate=False;Connection Timeout=30;

======= AZURE CON MANAGED IDENTITY =======
Server=tcp:miservidor.database.windows.net,1433;Database=MiBase;Authentication=Active Directory Managed Identity;Encrypt=True;

Ejemplo: Entity Framework Core (C#)

C#
// appsettings.json
{
  "ConnectionStrings": {
    "Default": "Server=localhost;Database=MiBase;User Id=sa;Password=MiPass123;TrustServerCertificate=True;"
  }
}

// DbContext
public class AppDbContext : DbContext
{
    public DbSet<Usuario> Usuarios { get; set; }

    protected override void OnConfiguring(DbContextOptionsBuilder ob)
        => ob.UseSqlServer(connectionString);
}

Ejemplo: Sequelize (Node.js)

JavaScript
const { Sequelize } = require('sequelize');

const sequelize = new Sequelize('MiBase', 'sa', 'MiPass123', {
    host: 'localhost',
    dialect: 'mssql',
    dialectOptions: {
        options: { encrypt: true, trustServerCertificate: true }
    },
    pool: { max: 5, min: 0, idle: 10000 }
});

const Usuario = sequelize.define('Usuario', {
    id: { type: DataTypes.INTEGER, primaryKey: true },
    nombre: DataTypes.STRING,
    email: DataTypes.STRING
});

Ejemplo: SQLAlchemy (Python)

Python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, Session

conn_str = "mssql+pyodbc://sa:MiPass123@localhost:1433/MiBase?driver=ODBC+Driver+18+for+SQL+Server&Encrypt=yes&TrustServerCertificate=yes"
engine = create_engine(conn_str)

Base = declarative_base()

class Usuario(Base):
    __tablename__ = 'Usuarios'
    id = Column(Integer, primary_key=True)
    nombre = Column(String)
    email = Column(String)

# Consulta
with Session(engine) as session:
    usuarios = session.query(Usuario).all()
