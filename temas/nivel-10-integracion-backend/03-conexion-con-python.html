Conexión con Python

Python se conecta a SQL Server principalmente mediante pyodbc o pymssql. La opción más recomendada es pyodbc con el driver ODBC de Microsoft.

ODBC Driver

Necesitas instalar el ODBC Driver for SQL Server (versión 17 o 18) desde Microsoft. En Linux: curl https://packages.microsoft.com/keys/microsoft.asc | apt-key add - y luego instala msodbcsql18.

Bibliotecas de Python para SQL Server

BibliotecaDriverComentario

Conexión Básica con pyodbc

Python
import pyodbc

conn_str = (
    'DRIVER={ODBC Driver 18 for SQL Server};'
    'SERVER=localhost;'
    'DATABASE=MiBase;'
    'UID=sa;'
    'PWD=ContraseñaSegura;'
    'Encrypt=yes;'
    'TrustServerCertificate=yes;'
)

conn = pyodbc.connect(conn_str)
cursor = conn.cursor()

# Consulta con parámetros
cursor.execute(
    'SELECT * FROM Usuarios WHERE email = ?',
    'user@example.com'
)

for row in cursor.fetchall():
    print(row.nombre, row.email)

cursor.close()
conn.close()

Integración con Pandas

Python
import pandas as pd
from sqlalchemy import create_engine

# Conexión vía SQLAlchemy + pyodbc
conn_str = (
    'mssql+pyodbc://sa:ContraseñaSegura@localhost:1433/MiBase'
    '?driver=ODBC+Driver+18+for+SQL+Server'
    '&Encrypt=yes&TrustServerCertificate=yes'
)

engine = create_engine(conn_str)

# Leer directamente a DataFrame
df = pd.read_sql('SELECT * FROM Ventas WHERE fecha >= :fecha',
                 engine, params={'fecha': '2026-01-01'})

# Escribir DataFrame a SQL Server
df.to_sql('Ventas_Backup', engine, if_exists='replace', index=False)

print(df.head())

Transacciones

Python
conn = pyodbc.connect(conn_str)
conn.autocommit = False

try:
    cursor = conn.cursor()
    cursor.execute("INSERT INTO Log (msg) VALUES ('Inicio')")
    cursor.execute("UPDATE Cuenta SET saldo = saldo - 100 WHERE id = 1")
    conn.commit()
except Exception as e:
    conn.rollback()
    print('Transacción revertida:', e)
finally:
    conn.close()
