Entornos Locales: Laragon, XAMPP, Docker

Configurar SQL Server localmente para desarrollo puede hacerse de varias formas. Cada opción tiene ventajas según el stack y las necesidades del proyecto.

Docker para aislamiento

Usar Docker para SQL Server en desarrollo evita conflictos con otras instalaciones, permite cambiar de versión fácilmente y replica fielmente el entorno de producción.

Laragon

Laragon incluye un gestor de servicios que permite instalar SQL Server Express con un clic (versión 2019/2022). Provee aislamiento de proyectos con .env automático.

.env
DB_CONNECTION=sqlsrv
DB_HOST=localhost
DB_PORT=1433
DB_DATABASE=MiBase
DB_USERNAME=sa
DB_PASSWORD=

Docker (recomendado)

SQL Server en Docker funciona en Windows, macOS y Linux. El contenedor oficial de Microsoft es ligero y fácil de configurar.

YAML
# docker-compose.yml
version: '3.8'

services:
  sqlserver:
    image: mcr.microsoft.com/mssql/server:2022-latest
    container_name: sqlserver-dev
    environment:
      ACCEPT_EULA: "Y"
      MSSQL_SA_PASSWORD: "DevPassword123!"
      MSSQL_PID: "Developer"
    ports:
      - "1433:1433"
    volumes:
      - sqlserver-data:/var/opt/mssql

volumes:
  sqlserver-data:
Bash
# Iniciar contenedor
docker-compose up -d

# Conectarse desde SSMS o cualquier cliente
# Servidor: localhost, 1433
# Usuario: sa
# Password: DevPassword123!

# Ejecutar script SQL dentro del contenedor
docker exec -it sqlserver-dev /opt/mssql-tools/bin/sqlcmd \
    -S localhost -U sa -P DevPassword123! \
    -d master -i /scripts/init.sql

XAMPP + ODBC

XAMPP no incluye SQL Server nativamente, pero puedes conectarte desde PHP a un SQL Server existente (local o remoto) mediante el ODBC Driver de Microsoft.

  1. Descarga e instala ODBC Driver 18 for SQL Server
  2. Habilita la extensión pdo_sqlsrv o sqlsrv en php.ini
  3. Usa el DSN de conexión como se muestra en la lección de PHP

Variables de Entorno (.env)

Gestiona las credenciales fuera del código usando archivos .env:

TEXTO
DB_SERVER=localhost
DB_PORT=1433
DB_NAME=MiBase
DB_USER=sa
DB_PASS=DevPassword123!
DB_ENCRYPT=true
DB_TRUST_CERT=true

Y cárgalas con la biblioteca correspondiente (dotenv en Node.js, python-dotenv, vlucas/phpdotenv, etc.).
