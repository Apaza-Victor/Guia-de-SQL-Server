Conexión con Node.js

El paquete mssql es el estándar para conectar Node.js con SQL Server. Utiliza internamente el driver tedious y soporta pool de conexiones, prepared statements y streaming.

Connection Pooling

Siempre usa un pool de conexiones (sql.connect() con pool.max) en lugar de abrir y cerrar una conexión por cada solicitud. Esto mejora drásticamente el rendimiento.

Conexión y Consulta

JavaScript
const sql = require('mssql');

const config = {
    server: 'localhost',
    database: 'MiBase',
    user: 'sa',
    password: 'ContraseñaSegura',
    options: {
        encrypt: true,
        trustServerCertificate: true,
    },
    pool: {
        max: 10,
        min: 0,
        idleTimeoutMillis: 30000,
    },
};

async function getUsuarios() {
    try {
        const pool = await sql.connect(config);

        const result = await pool
            .request()
            .input('email', sql.VarChar, 'user@example.com')
            .query('SELECT * FROM Usuarios WHERE email = @email');

        console.log(result.recordset);

        await pool.close();
    } catch (err) {
        console.error('Error:', err);
    }
}

getUsuarios();

Transacciones

JavaScript
const transaction = new sql.Transaction(pool);

try {
    await transaction.begin();

    const request = new sql.Request(transaction);
    await request.query('INSERT INTO Log (msg) VALUES (\'Inicio\')');
    await request.query('UPDATE Cuenta SET saldo = saldo - 100 WHERE id = 1');

    await transaction.commit();
} catch (err) {
    await transaction.rollback();
    console.error('Transacción revertida:', err);
}

Manejo de Errores

Captura sql.ConnectionError, sql.RequestError y sql.TransactionError para un manejo granular.

JavaScript
try {
    const pool = await sql.connect(config);
    const result = await pool.request().query('SELECT 1');
} catch (err) {
    if (err instanceof sql.ConnectionError) {
        console.error('Error de conexión:', err.message);
    } else if (err instanceof sql.RequestError) {
        console.error('Error en consulta:', err.message);
    }
}
