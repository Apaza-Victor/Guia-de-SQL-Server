Manejo de Errores TRY/CATCH

SQL Server proporciona un mecanismo estructurado de manejo de errores mediante los bloques TRY...CATCH. Similar a otros lenguajes, permite capturar excepciones en tiempo de ejecución y tomar acciones correctivas.

Estructura Básica

T-SQL
BEGIN TRY
    -- Instrucciones que pueden fallar
    INSERT INTO productos (nombre, precio)
    VALUES('Producto X', 100);
    PRINT 'Inserción exitosa';
END TRY
BEGIN CATCH
    -- Captura y maneja el error
    PRINT 'Ocurrió un error';
    PRINT ERROR_MESSAGE();
END CATCH;

Funciones de Error

Dentro del bloque CATCH se pueden usar las siguientes funciones para obtener detalles del error:

FunciónDescripción
ERROR_NUMBER()Número del error (ej. 2627 para violación de PK)
ERROR_MESSAGE()Texto completo del mensaje de error
ERROR_SEVERITY()Nivel de severidad (11-16 para errores de usuario)
ERROR_STATE()Código de estado del error
ERROR_LINE()Número de línea donde ocurrió el error
ERROR_PROCEDURE()Nombre del SP o trigger donde ocurrió
T-SQL
BEGIN TRY
    UPDATE productos SET precio = precio / 0;  -- División por cero
END TRY
BEGIN CATCH
    SELECT
        ERROR_NUMBER() AS NumError,
        ERROR_SEVERITY() AS Severidad,
        ERROR_STATE() AS Estado,
        ERROR_LINE() AS Linea,
        ERROR_MESSAGE() AS Mensaje;
END CATCH;

THROW vs RAISERROR

CaracterísticaTHROWRAISERROR
IntroducidoSQL Server 2012SQL Server 2000
Relanzar error capturadoTHROW; (sin parámetros)No directamente
Número de errorDebe estar en sys.messages o usar 50000Admite cualquier número
Parámetros estilo printfNoSí
SET XACT_ABORTTHROW fuerza terminaciónDepende de la severidad
T-SQL
-- THROW moderno
THROW 50000, 'Error personalizado', 1;

-- RAISERROR (heredado)
RAISERROR('Error personalizado: %s', 16, 1, 'detalle');

TRY/CATCH con Transacciones

T-SQL
BEGIN TRY
    BEGIN TRANSACTION;
        INSERT INTO ordenes (cliente_id, total) VALUES (1, 500);
        INSERT INTO detalle_orden (orden_id, producto_id, cantidad)
            VALUES (SCOPE_IDENTITY(), 10, 2);
    COMMIT TRANSACTION;
END TRY
BEGIN CATCH
    ROLLBACK TRANSACTION;
    THROW;  -- Relanza el error al llamador
END CATCH;
XACT_ABORT

Cuando SET XACT_ABORT ON, cualquier error termina automáticamente la transacción y la deshace. THROW respeta esta configuración. RAISERROR no, a menos que tenga severidad ≥ 18. Es buena práctica usar SET XACT_ABORT ON en procedimientos que manejan transacciones.

TRY/CATCH Anidados

T-SQL
BEGIN TRY
    -- Código externo
    BEGIN TRY
        -- Código interno
    END TRY
    BEGIN CATCH
        -- Manejo interno
        THROW;  -- Relanza al CATCH externo
    END CATCH;
END TRY
BEGIN CATCH
    -- Manejo externo
    PRINT 'Error capturado externamente: ' + ERROR_MESSAGE();
END CATCH;
/* --- Fin de Manejo de Errores --- */
