Triggers

Un trigger es un tipo especial de procedimiento almacenado que se ejecuta automáticamente en respuesta a eventos DML (INSERT, UPDATE, DELETE) sobre una tabla o vista. Son útiles para auditoría, validaciones complejas y mantener integridad referencial adicional.

Tablas inserted y deleted

SQL Server expone dos tablas lógicas dentro del trigger:

  • inserted: contiene las filas nuevas (INSERT) o los valores posteriores (UPDATE).
  • deleted: contiene las filas eliminadas (DELETE) o los valores anteriores (UPDATE).
T-SQL
CREATE TRIGGER trgAuditoriaProductos
ON productos
AFTER INSERT, UPDATE, DELETE
AS
BEGIN
    SET NOCOUNT ON;
    DECLARE @Operacion VARCHAR(10);

    IF EXISTS (SELECT 1 FROM inserted) AND EXISTS (SELECT 1 FROM deleted)
        SET @Operacion = 'UPDATE';
    ELSE IF EXISTS (SELECT 1 FROM inserted)
        SET @Operacion = 'INSERT';
    ELSE
        SET @Operacion = 'DELETE';

    INSERT INTO auditoria_productos
    (id_producto, nombre, precio_anterior, precio_nuevo, operacion, usuario, fecha)
    SELECT
        ISNULL(i.id_producto, d.id_producto),
        ISNULL(i.nombre, d.nombre),
        d.precio, i.precio,
        @Operacion,
        SYSTEM_USER,
        GETDATE()
    FROM inserted i
    FULL OUTER JOIN deleted d ON i.id_producto = d.id_producto;
END;

Trigger INSTEAD OF

T-SQL
CREATE TRIGGER trgInsteadOfDelete
ON clientes
INSTEAD OF DELETE
AS
BEGIN
    -- En lugar de eliminar, marca como inactivo
    UPDATE clientes
    SET activo = 0, fecha_baja = GETDATE()
    FROM clientes c
    INNER JOIN deleted d ON c.id_cliente = d.id_cliente;
END;

Habilitar / Deshabilitar Triggers

T-SQL
DISABLE TRIGGER trgAuditoriaProductos ON productos;
ENABLE TRIGGER trgAuditoriaProductos ON productos;
Recursión y efectos secundarios

Los triggers pueden provocar recursión (un trigger que modifica la misma tabla y se dispara a sí mismo) y efectos colaterales inesperados. Usa RECURSIVE_TRIGGERS con precaución y evita lógica compleja dentro de triggers. Los triggers también afectan el rendimiento de las operaciones DML porque se ejecutan dentro de la misma transacción.
