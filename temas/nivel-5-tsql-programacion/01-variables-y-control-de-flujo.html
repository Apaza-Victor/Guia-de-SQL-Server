Variables y Control de Flujo

La programación en T-SQL permite escribir lógica procedural dentro de SQL Server mediante variables, estructuras de control y expresiones condicionales. Este tema cubre las construcciones fundamentales que usarás en procedimientos almacenados, funciones y scripts.

Declaración de Variables — DECLARE

Las variables se declaran con DECLARE especificando nombre (precedido de @) y tipo de datos.

T-SQL
DECLARE @Nombre VARCHAR(50);
DECLARE @Edad INT = 30;
DECLARE @Precio DECIMAL(10,2), @Cantidad INT;

Asignación: SET vs SELECT

Ambos asignan valores a variables, pero con diferencias importantes:

CaracterísticaSETSELECT
Estándar ANSISíNo
Asignar múltiples varsRequiere múltiples SETUna sola instrucción
Origen de datosSolo escalar/subconsultaDesde tabla o consulta
Varias filas devueltasErrorToma la última fila
T-SQL
-- SET
SET @Nombre = (SELECT TOP 1 nombre FROM clientes WHERE id = 1);

-- SELECT
SELECT @Precio = precio, @Cantidad = stock
FROM productos WHERE id_producto = 10;
Ámbito de variables

Las variables en T-SQL tienen ámbito local al bloque o lote en que se declaran. Una vez que el lote finaliza (con GO), las variables dejan de existir. No persisten entre lotes ni entre sesiones.

Control de Flujo

IF / ELSE

T-SQL
DECLARE @Stock INT = 5;
IF @Stock > 10
    PRINT 'Stock suficiente';
ELSE IF @Stock > 0
    PRINT 'Stock bajo, reponer pronto';
ELSE
    PRINT 'Sin stock';

-- Con bloque BEGIN...END
IF EXISTS (SELECT 1 FROM productos WHERE precio > 1000)
BEGIN
    PRINT 'Hay productos caros';
    UPDATE productos SET descuento = 0.10 WHERE precio > 1000;
END

WHILE, BREAK y CONTINUE

T-SQL
DECLARE @i INT = 1;
WHILE @i <= 10
BEGIN
    IF @i = 5
    BEGIN
        SET @i = @i + 1;
        CONTINUE;  -- Salta el resto e itera de nuevo
    END
    IF @i = 9
        BREAK;     -- Sale del ciclo
    PRINT @i;
    SET @i = @i + 1;
END

Expresión CASE

Evalúa condiciones y devuelve un valor. Se usa en consultas SELECT, WHERE, ORDER BY y asignaciones.

T-SQL
-- CASE simple
SELECT nombre,
       CASE categoria
           WHEN 'A' THEN 'Alta'
           WHEN 'B' THEN 'Media'
           WHEN 'C' THEN 'Baja'
           ELSE 'Desconocida'
       END AS categoriaTexto
FROM productos;

-- CASE buscado
SELECT nombre,
       CASE
           WHEN precio < 50  THEN 'Económico'
           WHEN precio < 200 THEN 'Medio'
           ELSE 'Premium'
       END AS rango
FROM productos;

Resumen de Constructos de Control de Flujo

ConstructoPropósito

BREAKSale del ciclo WHILE inmediatamente
CONTINUESalta a la siguiente iteración del WHILE
