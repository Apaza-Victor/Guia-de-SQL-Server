Funciones Definidas por Usuario

Las funciones definidas por el usuario (UDF) encapsulan lógica que devuelve un valor escalar o una tabla. Se invocan dentro de consultas SELECT, WHERE, JOIN y asignaciones, lo que las distingue de los procedimientos almacenados.

Tipos de Funciones

TipoDevuelveSe usa enEjemplo
EscalarValor único (cualquier tipo)SELECT, WHERE, asignacionesdbo.Suma(1,2)
Inline TVFTabla (una sola SELECT)FROM, JOIN, CROSS APPLYdbo.ClientesActivos()
Multi-statement TVFTabla (múltiples instrucciones)FROM, JOIN, CROSS APPLYdbo.Reporte(@fecha)

Función Escalar

T-SQL
CREATE FUNCTION dbo.ObtenerNombreCompleto
(
    @Nombre VARCHAR(50),
    @Apellido VARCHAR(50)
)
RETURNS VARCHAR(101)
AS
BEGIN
    RETURN TRIM(@Nombre + ' ' + @Apellido);
END;

-- Uso
SELECT dbo.ObtenerNombreCompleto(nombre, apellido) AS nombre_completo
FROM clientes;
Rendimiento de funciones escalares en WHERE

Usar una función escalar en la cláusula WHERE puede degradar el rendimiento, ya que se ejecuta por cada fila (row-by-row) e impide el uso eficiente de índices. Prefiere columnas calculadas persistentes o expandir la lógica en la consulta cuando sea posible.

Inline Table-Valued Function (TVF)

T-SQL
CREATE FUNCTION dbo.PedidosPorCliente
(
    @ClienteID INT
)
RETURNS TABLE
AS
RETURN
    SELECT id_pedido, fecha, total
    FROM pedidos
    WHERE id_cliente = @ClienteID;

-- Uso
SELECT * FROM dbo.PedidosPorCliente(42)
WHERE total > 100;

Las inline TVF se comportan como vistas parametrizadas y el optimizador las expande en la consulta principal, permitiendo un mejor plan de ejecución.

Multi-Statement TVF

T-SQL
CREATE FUNCTION dbo.ResumenVentas
(
    @FechaInicio DATE,
    @FechaFin DATE
)
RETURNS @Resultado TABLE
(
    categoria VARCHAR(50),
    total_ventas DECIMAL(18,2),
    cantidad INT
)
AS
BEGIN
    INSERT @Resultado
    SELECT c.nombre, SUM(v.total), COUNT(v.id_venta)
    FROM ventas v
    JOIN productos p ON v.id_producto = p.id_producto
    JOIN categorias c ON p.id_categoria = c.id_categoria
    WHERE v.fecha BETWEEN @FechaInicio AND @FechaFin
    GROUP BY c.nombre;

    RETURN;
END;

Función vs Procedimiento Almacenado

A diferencia de los SP, las funciones deben devolver un valor (escalar o tabla), no pueden modificar datos (excepto variables tabla internas), y se invocan directamente en consultas.
