SSMS y Azure Data Studio

Para interactuar con SQL Server necesitas una herramienta de administración. Las dos principales son SQL Server Management Studio (SSMS) y Azure Data Studio (ADS). Ambas son gratuitas y se complementan entre sí.

SQL Server Management Studio (SSMS)

SSMS es la herramienta tradicional de Microsoft para administrar SQL Server. Está disponible solo para Windows y ofrece una interfaz completa para tareas de administración, desarrollo y monitoreo.

Instalación

Descarga la última versión desde el sitio oficial de Microsoft. El instalador es independiente de SQL Server. Una vez instalado, conéctate a tu instancia usando el nombre del servidor y el método de autenticación configurado.

Interfaz principal

  • Object Explorer — navegador de objetos (bases de datos, tablas, procedimientos, etc.).
  • Query Editor — editor de código T-SQL con resaltado de sintaxis e IntelliSense.
  • Solution Explorer — organiza proyectos y scripts.
  • Template Explorer — plantillas de código reutilizables.

Azure Data Studio (ADS)

Azure Data Studio es una herramienta moderna, multiplataforma (Windows, macOS, Linux) y de código abierto. Está orientada al desarrollo de consultas y se integra con Azure y GitHub Copilot.

Características destacadas

  • Editor con pestañas y cuadros de resultados integrados.
  • Soporte para extensiones (temas, conectores, notebooks).
  • Integración con Git y control de versiones.
  • Dashboards personalizables para monitoreo.
  • Terminal integrado y soporte para Kubernetes.

Nota

Ambas herramientas pueden instalarse en paralelo y usarse para distintos propósitos. Usa SSMS para tareas administrativas (crear logins, backups, configuración) y Azure Data Studio para desarrollo de consultas, análisis de datos y notebooks.

Conectar a SQL Server desde SSMS

T-SQL 
-- Consulta de prueba una vez conectado
SELECT
  SERVERPROPERTY('MachineName') AS [Equipo],
  SERVERPROPERTY('Edition') AS [Edición],
  SERVERPROPERTY('ProductVersion') AS [Versión];
/* --- fin de herramientas --- */
