Instalación de SQL Server

Antes de comenzar a trabajar con SQL Server, es necesario instalarlo en tu equipo. Microsoft ofrece varias ediciones, siendo las más comunes para aprendizaje Developer (gratuita, con todas las características) y Express (gratuita, limitada).

Requisitos del sistema

  • Sistema operativo: Windows 10/11 (64 bits) o Windows Server 2019+
  • Procesador: 1.4 GHz o superior (64 bits)
  • RAM: Mínimo 1 GB (512 MB para Express)
  • Disco: 6 GB de espacio libre
  • .NET Framework 4.7.2 o superior

Descarga

Puedes descargar SQL Server desde el sitio oficial de Microsoft. La edición Developer es la recomendada para aprendizaje, ya que incluye todas las funcionalidades de la edición Enterprise sin costo.

Tip

Para aprender SQL Server, elige la edición Developer. Es completamente gratuita y no tiene limitaciones de características. Solo no puede usarse en producción.

Pasos de instalación

  1. Ejecutar el instalador — haz doble clic en SQL2022-SSEI-Dev.exe (o similar).
  2. Elegir tipo de instalación — selecciona "Básica" para una instalación rápida o "Personalizada" para elegir componentes.
  3. Aceptar términos — acepta la licencia y espera a que se descarguen los archivos.
  4. Seleccionar características — marca al menos Database Engine Services.
  5. Configurar instancia — usa el nombre predeterminado MSSQLSERVER o asigna uno personalizado.
  6. Autenticación — elige "Modo mixto" (Windows + SQL Server) y establece una contraseña para sa.
  7. Instalar — haz clic en "Instalar" y espera a que finalice el proceso.

Herramientas incluidas

  • SQL Server Management Studio (SSMS) — herramienta gráfica para administrar SQL Server.
  • SQL Server Configuration Manager — administra servicios y configuraciones de red.
  • Azure Data Studio — editor multiplataforma moderno (se descarga por separado).
  • SQL Server Agent — programación de tareas automatizadas.

Verificar la instalación

Para confirmar que SQL Server está funcionando correctamente:

T-SQL 
SELECT @@VERSION AS [Versión];
GO
Nota

Si ves un mensaje de error al conectarte, verifica que el servicio "SQL Server (MSSQLSERVER)" esté en ejecución. Puedes revisarlo desde Services (services.msc) o desde SQL Server Configuration Manager.
