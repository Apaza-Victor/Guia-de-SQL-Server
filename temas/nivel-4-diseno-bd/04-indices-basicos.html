Índices en SQL Server

Un índice es una estructura de datos que mejora la velocidad de las consultas al permitir búsquedas rápidas sin escanear toda la tabla. Es similar al índice de un libro.

Estructura B-Tree

Clustered Index

Define el orden físico de los datos en la tabla. Solo puede haber un clustered index por tabla (la tabla se ordena físicamente). La PK crea un clustered index por defecto.

T-SQL 
-- Crear clustered index en una columna
CREATE CLUSTERED INDEX IX_Clientes_ClienteID
ON Clientes (ClienteID);

-- Clustered index compuesto
CREATE CLUSTERED INDEX IX_PedidoProducto_Compuesto
ON PedidoProducto (PedidoID, ProductoID);

Non-Clustered Index

Estructura separada que contiene las columnas indexadas y un puntero a la fila de datos. Puede haber múltiples non-clustered indexes por tabla.

T-SQL 
-- Índice simple en una columna
CREATE NONCLUSTERED INDEX IX_Clientes_Email
ON Clientes (Email);

-- Índice compuesto (varias columnas)
CREATE NONCLUSTERED INDEX IX_Productos_Categoria_Precio
ON Productos (CategoriaID, Precio DESC);

-- Índice con columnas incluidas (cubre la consulta sin tocar la tabla)
CREATE NONCLUSTERED INDEX IX_Pedidos_Cliente_Include
ON Pedidos (ClienteID)
INCLUDE (Fecha, Total);

Índice compuesto

Índice sobre múltiples columnas. El orden de las columnas importa: las columnas más selectivas primero.

T-SQL 
-- Bueno para consultas con Category y luego Price
CREATE INDEX IX_Productos_Cat_Precio
ON Productos (Category, Price);

-- Este índice funciona bien para:
SELECT * FROM Productos WHERE Category = 'Electrónica' AND Price > 100;
SELECT * FROM Productos WHERE Category = 'Electrónica';
-- Pero NO para:
SELECT * FROM Productos WHERE Price > 100;  -- Solo Price

Advertencia

El sobre-indexamiento puede degradar el rendimiento de escritura. Cada índice adicional aumenta el tiempo de INSERT, UPDATE y DELETE porque SQL Server debe mantener todos los índices sincronizados. Indexa solo las columnas que realmente se usan en condiciones WHERE, JOINs y ORDER BY.

Ver y analizar índices

T-SQL 
-- Ver índices de una tabla
EXEC sp_helpindex 'Clientes';

-- Reorganizar un índice (desfragmentación ligera)
ALTER INDEX IX_Clientes_Email ON Clientes REORGANIZE;

-- Reconstruir un índice (desfragmentación completa)
ALTER INDEX IX_Clientes_Email ON Clientes REBUILD;
/* --- fin de índices --- */
