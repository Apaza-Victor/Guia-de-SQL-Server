Vistas en SQL Server

Una vista (VIEW) es una tabla virtual cuyo contenido está definido por una consulta. No almacena datos físicamente (salvo las vistas indexadas), sino que es una representación de los datos subyacentes.

CREATE VIEW

T-SQL 
-- Vista básica
CREATE VIEW Vista_ClientesActivos AS
SELECT CustomerID, Name, City
FROM Customers
WHERE Activo = 1;

-- Vista con columnas calculadas y alias
CREATE VIEW Vista_ResumenVentas AS
SELECT
    Category,
    COUNT(*) AS TotalTransacciones,
    SUM(Quantity * UnitPrice) AS IngresosTotales,
    AVG(UnitPrice) AS PrecioPromedio
FROM Sales
GROUP BY Category;

-- Consultar una vista
SELECT * FROM Vista_ResumenVentas
ORDER BY IngresosTotales DESC;

¿Por qué usar vistas?

  • Seguridad — ocultar columnas sensibles (contraseñas, salarios) y exponer solo datos necesarios.
  • Simplicidad — encapsular consultas complejas para que los usuarios solo hagan SELECT * FROM Vista.
  • Consistencia — centralizar la lógica de negocio; si cambia la estructura subyacente, solo se modifica la vista.
  • Reutilización — una misma vista puede ser usada por múltiples aplicaciones y reportes.

Modificar y eliminar vistas

T-SQL 
-- Modificar vista existente
CREATE OR ALTER VIEW Vista_ResumenVentas AS
SELECT
    Category,
    ProductName,
    SUM(Quantity * UnitPrice) AS IngresosTotales
FROM Sales
GROUP BY Category, ProductName;

-- Eliminar una vista
DROP VIEW IF EXISTS Vista_ClientesActivos;

-- Obtener definición de una vista
EXEC sp_helptext 'Vista_ResumenVentas';

Actualizar datos a través de vistas

En ciertas condiciones, puedes ejecutar INSERT, UPDATE y DELETE a través de una vista.

T-SQL 
CREATE VIEW Vista_Clientes AS
SELECT CustomerID, Name, City FROM Customers;

-- Actualizar a través de la vista
UPDATE Vista_Clientes
SET City = 'Sevilla'
WHERE CustomerID = 1;

-- WITH CHECK OPTION: evita insertar filas que no cumplan la condición de la vista
CREATE VIEW Vista_ClientesMadrid AS
SELECT CustomerID, Name, City
FROM Customers
WHERE City = 'Madrid'
WITH CHECK OPTION;

-- Esto fallaría porque la ciudad sería 'Barcelona', no 'Madrid'
INSERT INTO Vista_ClientesMadrid (CustomerID, Name, City)
VALUES (99, 'Test', 'Barcelona');

Vistas indexadas (materializadas)

Una vista indexada almacena físicamente los datos y los mantiene sincronizados. Mejora drásticamente el rendimiento de consultas agregadas.

T-SQL 
-- Requiere SCHEMABINDING y ciertas restricciones
CREATE VIEW Vista_VentasDiarias WITH SCHEMABINDING AS
SELECT
    SaleDate,
    COUNT_BIG(*) AS TotalTransacciones,
    SUM(ISNULL(Quantity * UnitPrice, 0)) AS Ingresos
FROM dbo.Sales
GROUP BY SaleDate;

-- Crear índice clúster sobre la vista
CREATE UNIQUE CLUSTERED INDEX IX_Vista_VentasDiarias
ON Vista_VentasDiarias (SaleDate);
Nota

Las vistas indexadas tienen un costo de mantenimiento: cada modificación en las tablas base debe reflejarse en el índice. Úsalas solo cuando las consultas sean mucho más frecuentes que las escrituras.
