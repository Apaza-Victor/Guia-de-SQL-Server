Funciones agregadas y GROUP BY

Las funciones agregadas realizan cálculos sobre un conjunto de filas y devuelven un solo resultado. La cláusula GROUP BY agrupa filas para aplicar estas funciones por categoría.

Tabla de ejemplo

T-SQL 
CREATE TABLE Sales (
    SaleID INT IDENTITY(1,1) PRIMARY KEY,
    ProductName NVARCHAR(100),
    Category NVARCHAR(50),
    Quantity INT,
    UnitPrice DECIMAL(10,2),
    SaleDate DATE
);

GROUP BY básico

T-SQL 
SELECT
    Category,
    COUNT(*) AS TotalVentas,
    SUM(Quantity) AS UnidadesVendidas,
    SUM(Quantity * UnitPrice) AS Ingresos,
    AVG(UnitPrice) AS PrecioPromedio,
    MIN(UnitPrice) AS PrecioMinimo,
    MAX(UnitPrice) AS PrecioMaximo
FROM Sales
GROUP BY Category;

GROUP BY con múltiples columnas

T-SQL 
SELECT
    Category,
    ProductName,
    SUM(Quantity) AS TotalUnidades,
    SUM(Quantity * UnitPrice) AS TotalIngresos
FROM Sales
GROUP BY Category, ProductName
ORDER BY Category, ProductName;

HAVING: filtrar grupos

HAVING filtra los resultados después de la agregación (a diferencia de WHERE, que filtra antes).

T-SQL 
SELECT
    ProductName,
    SUM(Quantity) AS UnidadesVendidas
FROM Sales
WHERE SaleDate >= '2024-01-01'  -- Filtro antes de agrupar
GROUP BY ProductName
HAVING SUM(Quantity) > 5         -- Filtro después de agrupar
ORDER BY UnidadesVendidas DESC;
Tip

Usa WHERE para filtrar filas antes de agrupar y HAVING para filtrar grupos después de la agregación. WHERE es más eficiente porque reduce los datos antes del GROUP BY.

GROUPING SETS, ROLLUP, CUBE

Permiten obtener múltiples niveles de agregación en una sola consulta.

T-SQL 
-- ROLLUP: subtotales jerárquicos
SELECT
    Category,
    ProductName,
    SUM(Quantity * UnitPrice) AS Ingresos
FROM Sales
GROUP BY ROLLUP(Category, ProductName);

-- CUBE: todas las combinaciones
SELECT
    Category,
    ProductName,
    SUM(Quantity * UnitPrice) AS Ingresos
FROM Sales
GROUP BY CUBE(Category, ProductName);

-- GROUPING SETS: combinaciones específicas
SELECT
    Category,
    ProductName,
    SUM(Quantity * UnitPrice) AS Ingresos
FROM Sales
GROUP BY GROUPING SETS(
    (Category),
    (ProductName),
    (Category, ProductName),
    ()
);

COUNT(DISTINCT columna)Cuenta valores únicos no NULL
SUM(columna)Suma de valores numéricos
