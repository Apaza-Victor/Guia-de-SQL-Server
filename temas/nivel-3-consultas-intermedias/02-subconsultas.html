Subconsultas en SQL Server

Una subconsulta es una consulta anidada dentro de otra consulta. Se usa para obtener datos intermedios que alimentan la consulta principal.

Subconsultas en WHERE (IN, EXISTS, NOT EXISTS)

T-SQL 
-- Clientes que han realizado pedidos (IN)
SELECT Name FROM Customers
WHERE CustomerID IN (
    SELECT DISTINCT CustomerID FROM Orders
);

-- Clientes sin pedidos (NOT IN)
SELECT Name FROM Customers
WHERE CustomerID NOT IN (
    SELECT DISTINCT CustomerID FROM Orders
    WHERE CustomerID IS NOT NULL
);

-- EXISTS (más eficiente que IN en tablas grandes)
SELECT c.Name FROM Customers c
WHERE EXISTS (
    SELECT 1 FROM Orders o
    WHERE o.CustomerID = c.CustomerID
);

-- NOT EXISTS
SELECT c.Name FROM Customers c
WHERE NOT EXISTS (
    SELECT 1 FROM Orders o
    WHERE o.CustomerID = c.CustomerID
);

Subconsultas escalares en SELECT

Devuelven un solo valor y se usan como columna calculada.

T-SQL 
SELECT
    c.Name,
    c.City,
    (SELECT COUNT(*) FROM Orders o WHERE o.CustomerID = c.CustomerID) AS TotalOrders,
    (SELECT ISNULL(SUM(o.Amount), 0) FROM Orders o WHERE o.CustomerID = c.CustomerID) AS TotalAmount
FROM Customers c;

Subconsultas en FROM (derived tables)

La subconsulta actúa como una tabla virtual en el FROM.

T-SQL 
SELECT dt.Category, dt.MaxPrice, p.Name
FROM Products p
INNER JOIN (
    SELECT Category, MAX(Price) AS MaxPrice
    FROM Products
    GROUP BY Category
) dt ON p.Category = dt.Category AND p.Price = dt.MaxPrice;

Subconsultas correlacionadas

La subconsulta hace referencia a columnas de la consulta externa. Se evalúa una vez por cada fila externa.

T-SQL 
-- Productos con precio mayor al promedio de su categoría
SELECT p1.Name, p1.Category, p1.Price
FROM Products p1
WHERE p1.Price > (
    SELECT AVG(p2.Price)
    FROM Products p2
    WHERE p2.Category = p1.Category
);
Nota

Las subconsultas correlacionadas pueden ser lentas en tablas grandes porque se ejecutan una vez por cada fila externa. Considera usar JOIN o Window Functions como alternativas más eficientes en muchos casos.
