JOINs en SQL Server

Los JOINs permiten combinar filas de dos o más tablas basándose en una condición relacionada. Son fundamentales para trabajar con bases de datos relacionales.

Tablas de ejemplo

T-SQL 
CREATE TABLE Customers (
    CustomerID INT PRIMARY KEY,
    Name NVARCHAR(100),
    City NVARCHAR(50)
);

CREATE TABLE Orders (
    OrderID INT PRIMARY KEY,
    CustomerID INT,
    Amount DECIMAL(10,2),
    OrderDate DATE
);

INSERT INTO Customers VALUES
(1, 'Ana López', 'Madrid'),
(2, 'Luis Gómez', 'Barcelona'),
(3, 'Elena Ruiz', 'Valencia');

INSERT INTO Orders VALUES
(101, 1, 150.00, '2024-01-15'),
(102, 1, 200.00, '2024-02-10'),
(103, 2, 75.00, '2024-01-20'),
(104, 5, 300.00, '2024-03-01');  -- Cliente 5 no existe

INNER JOIN

Devuelve solo las filas que tienen correspondencia en ambas tablas.

T-SQL 
SELECT c.Name, o.OrderID, o.Amount
FROM Customers c
INNER JOIN Orders o ON c.CustomerID = o.CustomerID;

LEFT JOIN

Devuelve todas las filas de la tabla izquierda y las coincidentes de la derecha. Las no coincidentes aparecen como NULL.

T-SQL 
SELECT c.Name, o.OrderID, o.Amount
FROM Customers c
LEFT JOIN Orders o ON c.CustomerID = o.CustomerID;

RIGHT JOIN

Devuelve todas las filas de la tabla derecha y las coincidentes de la izquierda.

T-SQL 
SELECT c.Name, o.OrderID, o.Amount
FROM Customers c
RIGHT JOIN Orders o ON c.CustomerID = o.CustomerID;

FULL OUTER JOIN

Devuelve todas las filas de ambas tablas, combinando donde sea posible.

T-SQL 
SELECT c.Name, o.OrderID, o.Amount
FROM Customers c
FULL OUTER JOIN Orders o ON c.CustomerID = o.CustomerID;

CROSS JOIN

Producto cartesiano: cada fila de la izquierda se combina con cada fila de la derecha.

T-SQL 
SELECT c.Name, o.OrderID
FROM Customers c
CROSS JOIN Orders o;

SELF JOIN

Una tabla se une consigo misma. Útil para estructuras jerárquicas.

T-SQL 
CREATE TABLE Employees (
    EmployeeID INT PRIMARY KEY,
    Name NVARCHAR(100),
    ManagerID INT NULL
);

INSERT INTO Employees VALUES
(1, 'Carlos Ruiz', NULL),
(2, 'Ana López', 1),
(3, 'Luis Gómez', 1),
(4, 'Elena Torres', 2);

SELECT e.Name AS Empleado, m.Name AS Jefe
FROM Employees e
LEFT JOIN Employees m ON e.ManagerID = m.EmployeeID;

Advertencia

En LEFT y RIGHT JOIN, las columnas de la tabla sin coincidencia devuelven NULL. Ten cuidado con los NULLs al usar condiciones WHERE adicionales.
