UNION, EXCEPT, INTERSECT

Los operadores de conjuntos permiten combinar los resultados de dos o más consultas en un solo conjunto de resultados.

Tablas de ejemplo

T-SQL 
CREATE TABLE Ventas2023 (
    Producto NVARCHAR(100),
    Monto DECIMAL(10,2)
);

CREATE TABLE Ventas2024 (
    Producto NVARCHAR(100),
    Monto DECIMAL(10,2)
);

INSERT INTO Ventas2023 VALUES
('Laptop', 5000), ('Mouse', 1200), ('Teclado', 800), ('Monitor', 3000);

INSERT INTO Ventas2024 VALUES
('Laptop', 5500), ('Mouse', 1500), ('Silla', 2000), ('Webcam', 900);

UNION vs UNION ALL

T-SQL 
-- UNION: elimina duplicados
SELECT Producto FROM Ventas2023
UNION
SELECT Producto FROM Ventas2024;
-- Resultado: Laptop, Mouse, Teclado, Monitor, Silla, Webcam

-- UNION ALL: conserva todos (más rápido)
SELECT Producto FROM Ventas2023
UNION ALL
SELECT Producto FROM Ventas2024;
-- Resultado: Laptop, Mouse, Teclado, Monitor, Laptop, Mouse, Silla, Webcam

EXCEPT

Devuelve las filas de la primera consulta que no existen en la segunda.

T-SQL 
-- Productos vendidos en 2023 pero no en 2024
SELECT Producto FROM Ventas2023
EXCEPT
SELECT Producto FROM Ventas2024;
-- Resultado: Teclado, Monitor

INTERSECT

Devuelve las filas que existen en ambas consultas.

T-SQL 
-- Productos vendidos tanto en 2023 como en 2024
SELECT Producto FROM Ventas2023
INTERSECT
SELECT Producto FROM Ventas2024;
-- Resultado: Laptop, Mouse
OperadorQué devuelveDuplicadosRendimiento
UNIONUnión de ambos conjuntosEliminadosMás lento (requiere ordenación)
UNION ALLUnión de ambos conjuntosConservadosMás rápido
EXCEPTFilas solo en el primer conjuntoEliminadosModerado
INTERSECTFilas comunes a ambos conjuntosEliminadosModerado

Reglas para operadores de conjuntos

  • El número y orden de las columnas debe coincidir en todas las consultas.
  • Los tipos de datos deben ser compatibles (o convertibles implícitamente).
  • ORDER BY solo puede ir al final de la consulta combinada.
  • Los nombres de columna se toman de la primera consulta.
T-SQL 
-- ORDER BY al final
SELECT Producto, SUM(Monto) AS Total
FROM Ventas2023
GROUP BY Producto
UNION
SELECT Producto, SUM(Monto)
FROM Ventas2024
GROUP BY Producto
ORDER BY Total DESC;

-- Uso combinado
SELECT 'Solo 2023' AS Periodo, Producto FROM Ventas2023
EXCEPT
SELECT 'Solo 2023', Producto FROM Ventas2024
UNION ALL
SELECT 'Ambos', Producto FROM Ventas2023
INTERSECT
SELECT 'Ambos', Producto FROM Ventas2024;
Advertencia

Los operadores EXCEPT e INTERSECT comparan valores NULL como iguales (a diferencia de NOT IN). Dos filas con NULL en la misma columna se consideran duplicados y se eliminan.
