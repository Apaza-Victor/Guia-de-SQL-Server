Tipos de datos en SQL Server

Elegir el tipo de dato correcto es fundamental para optimizar el rendimiento, el almacenamiento y la integridad de los datos. SQL Server ofrece una amplia variedad de tipos.

Tipos de cadena

TipoDescripciónAlmacenamiento
CHAR(n)Cadena de longitud fija (no Unicode)n bytes
VARCHAR(n)Cadena de longitud variable (no Unicode)Longitud real + 2 bytes
VARCHAR(MAX)Cadena variable hasta 2 GBLongitud real + 2 bytes
NCHAR(n)Cadena fija Unicode2n bytes

NVARCHAR(MAX)Cadena variable Unicode hasta 2 GBLongitud real*2 + 2 bytes
TEXTObsoleto, usar VARCHAR(MAX)Variable
NTEXTObsoleto, usar NVARCHAR(MAX)Variable
Tip

Usa NVARCHAR cuando necesites almacenar caracteres internacionales (acentos, ñ, caracteres chinos). Usa VARCHAR para datos en ASCII puro. NVARCHAR ocupa el doble de espacio.

Otros tipos

TipoDescripción
UNIQUEIDENTIFIERGUID de 16 bytes. Se genera con NEWID() o NEWSEQUENTIALID()
XMLAlmacena datos XML con hasta 2 GB
JSONNo hay tipo nativo; se usa NVARCHAR(MAX) con funciones JSON
HIERARCHYIDRepresenta posiciones en jerarquías
GEOGRAPHYDatos espaciales (latitud/longitud)
GEOMETRYDatos espaciales planos (puntos, polígonos)
ROWVERSIONNúmero binario único que se actualiza automáticamente por fila
SQL_VARIANTAlmacena valores de cualquier tipo de dato
Tip

Elige el tipo de dato más pequeño que pueda contener tus datos. Por ejemplo, usa SMALLINT en lugar de INT si el rango máximo es menor a 32,767. Esto reduce el espacio en disco y mejora el rendimiento de las consultas.
