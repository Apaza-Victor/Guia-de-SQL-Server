DDL: CREATE, ALTER, DROP

El DDL (Data Definition Language) es un subconjunto de SQL que permite definir y modificar la estructura de los objetos de la base de datos. Los comandos principales son CREATE, ALTER y DROP.

ComandoFunción
CREATECrea nuevos objetos (bases de datos, tablas, vistas, etc.)
ALTERModifica objetos existentes
DROPElimina objetos de la base de datos

CREATE DATABASE

Crea una nueva base de datos. Puedes especificar archivos de datos y de log, aunque los valores predeterminados suelen ser suficientes.

T-SQL 
CREATE DATABASE MiBaseDeDatos;
GO

-- Con opciones adicionales
CREATE DATABASE MiBaseDeDatos
ON PRIMARY (
    NAME = 'MiBaseDeDatos_Data',
    FILENAME = 'C:\Datos\MiBaseDeDatos.mdf',
    SIZE = 10MB,
    MAXSIZE = 100MB,
    FILEGROWTH = 5MB
)
LOG ON (
    NAME = 'MiBaseDeDatos_Log',
    FILENAME = 'C:\Datos\MiBaseDeDatos.ldf',
    SIZE = 5MB,
    MAXSIZE = 50MB,
    FILEGROWTH = 1MB
);
GO

CREATE TABLE

Define una nueva tabla con sus columnas, tipos de datos y restricciones.

T-SQL 
USE MiBaseDeDatos;
GO

CREATE TABLE Clientes (
    ClienteID INT IDENTITY(1,1) PRIMARY KEY,
    Nombre NVARCHAR(100) NOT NULL,
    Email NVARCHAR(200) NOT NULL UNIQUE,
    Telefono NVARCHAR(20) NULL,
    FechaRegistro DATETIME2 DEFAULT GETDATE(),
    Activo BIT DEFAULT 1
);
GO

ALTER TABLE

Modifica la estructura de una tabla existente.

T-SQL 
-- Agregar una columna
ALTER TABLE Clientes
ADD Direccion NVARCHAR(300) NULL;

-- Modificar el tipo de dato de una columna
ALTER TABLE Clientes
ALTER COLUMN Telefono NVARCHAR(30);

-- Eliminar una columna
ALTER TABLE Clientes
DROP COLUMN Direccion;

-- Agregar una restricción
ALTER TABLE Clientes
ADD CONSTRAINT CK_Telefono
CHECK (Telefono LIKE '[0-9]%');

DROP TABLE / DROP DATABASE

Elimina completamente un objeto de la base de datos.

T-SQL 
-- Eliminar una tabla
DROP TABLE IF EXISTS Clientes;

-- Eliminar una base de datos
DROP DATABASE IF EXISTS MiBaseDeDatos;
Advertencia

Los comandos DROP son irreversibles. Una vez ejecutados, los datos se pierden permanentemente (a menos que tengas un backup). Usa IF EXISTS para evitar errores si el objeto no existe.
