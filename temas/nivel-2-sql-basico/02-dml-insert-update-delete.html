DML: INSERT, UPDATE, DELETE

El DML (Data Manipulation Language) agrupa los comandos que manipulan los datos almacenados en las tablas: INSERT, UPDATE, DELETE y TRUNCATE.

INSERT INTO

Agrega nuevas filas a una tabla.

T-SQL 
-- Insertar una sola fila
INSERT INTO Clientes (Nombre, Email, Telefono)
VALUES ('Juan Pérez', 'juan@email.com', '555-1234');

-- Insertar múltiples filas
INSERT INTO Clientes (Nombre, Email, Telefono)
VALUES
    ('María García', 'maria@email.com', '555-5678'),
    ('Carlos López', 'carlos@email.com', '555-9012');

-- Insertar usando SELECT
INSERT INTO Clientes (Nombre, Email)
SELECT Nombre, Email FROM Clientes_Temp
WHERE Activo = 1;

UPDATE

Modifica los valores de una o más filas existentes.

T-SQL 
-- Actualizar una sola columna
UPDATE Clientes
SET Telefono = '555-9999'
WHERE ClienteID = 1;

-- Actualizar múltiples columnas
UPDATE Clientes
SET
    Nombre = 'Juan Pérez García',
    Email = 'juan.perez@email.com'
WHERE ClienteID = 1;

-- Actualizar todas las filas (con precaución)
UPDATE Clientes
SET Activo = 1;

DELETE vs TRUNCATE

T-SQL 
-- DELETE con condición
DELETE FROM Clientes
WHERE ClienteID = 10;

-- DELETE sin condición (elimina todas las filas)
DELETE FROM Clientes;

-- TRUNCATE (elimina todas las filas, más rápido)
TRUNCATE TABLE Clientes;
Peligro

Si omites la cláusula WHERE en un UPDATE o DELETE, la operación afectará a todas las filas de la tabla. Siempre verifica tu condición antes de ejecutar.
