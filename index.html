Cómo usar la guía

Lectura recomendada

La guía está diseñada para leerse de forma secuencial, pero cada tema también funciona como referencia independiente. Si ya tienes experiencia, puedes saltar al nivel que necesites.

  • Navega por niveles usando el menú superior o el grid del temario.
  • Cada tema incluye explicación teórica, ejemplos de código T-SQL, tablas comparativas y notas importantes.
  • Usa los botones "Anterior / Siguiente" al final de cada página para avanzar en orden.
  • Alterna el tema oscuro/claro con el botón de sol/luna en la barra superior.
  • Consulta la sección de Recursos para herramientas externas y el Glosario para términos técnicos.
